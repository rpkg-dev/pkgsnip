# List all available R Markdown file snippets

Lists all of the R Markdown snippets shipped with this package, together
with the paths where they're located on the filesystem.

## Usage

``` r
ls_file_snips()
```

## Value

A [tibble](https://tibble.tidyverse.org/reference/tbl_df-class.html).
